Live demo

GitHub activity, in plain English

This is the browser version of my github_user_tracker (opens in a new tab) CLI. Type any GitHub username and it reads their latest public events straight from GitHub’s API — nothing goes through a server of mine.

Try:

$ github-activity <username>

Results will appear here.

Shows up to 30 recent public events. Private work, like Both Homes, doesn’t appear here.
